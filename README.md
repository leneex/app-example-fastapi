# FastAPI

Пример приложения [FastAPI](https://fastapi.tiangolo.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/` |

Railpack видит FastAPI и uvicorn: ставит зависимости из `requirements.txt` и запускает
`uvicorn main:app` на порту из переменной окружения `PORT` — её передаёт платформа, — а без неё `8000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# виртуальное окружение и зависимости
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# запуск приложения
python3 main.py
```
